# 🔥 Incident · La PR que personne n'ose relire

> **De :** Sam, développeur  
> **À :** l'équipe de la Lanterne  
> **Salle :** Le Grenier · combat 12.3

Une PR « fix » attend une relecture depuis trois jours. Sa description : « voir code ». Personne ne sait ce qu'elle change, comment la tester, ni ce qu'elle risque de casser. Et le ticket LAN-42, lui, est toujours ouvert.

```text
PR #87  fix
  Description : voir code
  Relectures : 0 · ouverte depuis 3 jours
  Inès : « C'est pour LAN-42 ? On peut livrer ? »
```

**Le monstre :** Le Fantôme de l'imposteur. La petite voix qui te dit que tu n'es pas à ta place. On le fait taire avec des preuves.

**Ta mission :** la règle du ticket LAN-42, et une description que l'équipe relit sans poser de question.
La consigne complète est dans le manoir (combat 12.3, « Une description de PR conforme au modèle de l'équipe »).

Une fois ta pull request ouverte : onglet **Actions** → **Manoir** → **Run workflow**, branche
`exercice/description-pr`. Le résumé du run te dit combien de points de vie il reste au monstre.
